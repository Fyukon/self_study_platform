1. Запуск приложения конфигурация, сервер, graceful shutdown

Обычный запуск создаёт каталоги, открывает SQLite, применяет миграции, затем запускает seed и HTTP-сервер.

cmd/app/main.go

Точка входа. Флаги -port, -migrate-only, -seed-only; адрес по умолчанию 127.0.0.1:8080; таймауты и остановка по SIGTERM.

internal/config/config.go

Читает XDG-пути и создаёт config.json. Дефолты: Europe/Moscow, SQLite в ~/.local/share/learning-roadmap.

web/web_prod.go · web/web_dev.go

В production отдаёт Vite-файлы и fallback на index.html; в development направляет к Vite-серверу.

2. Данные и схема SQLite, UTC, индексы

Backend использует database/sql и один SQLite connection для локального single-user режима.

internal/database/database.go

Открывает SQLite, включает foreign keys/WAL, применяет embedded SQL и импортирует seed транзакционно.

migrations/0001_initial.sql

Таблицы settings, directions, roadmap_nodes, node_dependencies; CHECK-ограничения статусов/confidence и индексы дерева.

migrations/embed.go

Встраивает миграции в бинарник, поэтому отдельная директория миграций в production не нужна.

3. Seed Backend Go первый запуск, идемпотентность

Seed создаёт направление с 10 разделами, 86 узлами и 16 зависимостями. При наличии стабильного seed_key повторный запуск ничего не восстанавливает поверх пользовательских изменений.

seeds/backend_go_roadmap.json

Содержит дерево, статусы, confidence, next_action и зависимости между узлами.

seeds/embed.go

Делает JSON доступным через embed.FS.

docs/ROADMAP_IMPORT.md · docs/roadmap-template.json

Контракт roadmap для ручного создания и будущего bulk-import; описывает seed_key, дерево children, зависимости, статусы и безопасную проверку на отдельной базе.

4. HTTP API единая точка входа для UI

Все endpoints начинаются с /api/v1. Ошибки возвращаются как error.code/message/details; запросы логируются request_id, method, path, status и duration_ms.

internal/app/app.go

Маршруты, JSON-декодирование с body limit, recovery, request logging, health/version/settings.

internal/app/model.go

Go-модели Settings, Direction, RoadmapNode и NodeDependency; общая валидация статусов и confidence.

internal/app/settings_directions.go

CRUD directions и settings. Удаление направления — архивирование, не физическое удаление.

internal/app/roadmap.go

Рекурсивное дерево, CRUD узлов, move с проверкой циклов, зависимости и защита направления родителя.

5. Frontend экраны, состояние, API-клиент

React Router хранит выбранное направление в URL: /roadmap/1 или /roadmap?direction=1. Поэтому прямые ссылки и обновление страницы не теряют контекст.

web/src/main.tsx · web/src/App.tsx

Bootstrap React, BrowserRouter, навигация, темы и маршруты Dashboard/Roadmap.

web/src/Dashboard.tsx

Экран «Сегодня»: загружает активные roadmap, вычисляет повторение, просрочки, доступные действия, блокировки зависимостями и недельную активность.

web/src/RoadmapPage.tsx

Загрузка directions/roadmap, выбор направления и темы из URL (node), создание узлов, анимированная карточка каждой темы с описанием, готовностью и следующим шагом, полноэкранный режим карточки с закрытием по Esc, редактирование прогресса, управление зависимостями и hotkeys Esc/N/R.

web/src/RoadmapTree.tsx

Рекурсивное дерево с раскрытием веток и текстовыми статусами; общий helper flattenNodes используется Dashboard и RoadmapPage.

web/src/api.ts · web/src/types.ts

Минимальный fetch-клиент и типы API в snake_case.

web/src/icons.tsx · web/src/styles.css

Локальные inline SVG-иконки без UI-библиотеки, быстрые CSS-анимации карточек/скелетонов, кольца прогресса и общая светлая/тёмная тема.

web/public/architecture.html

Эта карта: native HTML details/summary раскрывает уровень ответственности до конкретных файлов.
