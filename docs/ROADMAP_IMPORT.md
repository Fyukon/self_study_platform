# Создание и загрузка roadmap

## Что поддерживается сейчас

В текущем MVP новые направления и темы добавляются через экран `Roadmap`:

1. Нажмите `+` рядом с «Направления» и создайте направление.
2. Откройте направление и нажмите «Новая тема» (`N` тоже работает).
3. Укажите название, тип, описание того, что изучить, и следующий шаг.
4. В карточке темы настройте статус, уверенность, повторение и зависимости.

Произвольная загрузка JSON через веб-интерфейс пока не включена. JSON ниже —
контракт для bulk-import, который будет добавлен следующим этапом. Не загружайте
непроверенный файл напрямую в production-базу.

## Формат файла

Скопируйте [`roadmap-template.json`](roadmap-template.json) и измените:

- `seed_key` — стабильный уникальный ключ всего roadmap;
- `nodes[].seed_key` — уникальный ключ каждого узла;
- `children` — вложенные разделы и темы;
- `dependencies` — связи по `node_seed_key` и `depends_on_seed_key`;
- `target_date` — дата в формате `YYYY-MM-DD` или `null`;
- `node_type` — `section`, `concept`, `practice`, `project`, `checkpoint`;
- `status` — `not_started`, `learning`, `practicing`, `understood`.

`position` начинается с `1` среди соседей. `confidence` — целое число от `1` до
`5`, `estimated_hours` — неотрицательное число. Описание пишите обычным текстом;
переносы строк сохраняются в карточке темы.

## Встроенные seeds для разработки

Все JSON-файлы из `seeds/` встраиваются в бинарник и обрабатываются при запуске.
Сейчас встроены `backend_go_roadmap.json` и `rust_roadmap.json`.

Чтобы добавить ещё одно направление, создайте отдельный JSON с уникальным `seed_key`, затем запустите:

```sh
make build
./dist/learning-roadmap -seed-only
```

Каждый seed импортируется только если направление с таким `seed_key` ещё не существует.
Повторный запуск не восстанавливает удалённые пользователем узлы уже импортированного направления.
Для проверки используйте отдельные `XDG_DATA_HOME` и `XDG_CONFIG_HOME`; не
перезаписывайте рабочую базу пользователя.
