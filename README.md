# Learning Roadmap

Локальное однопользовательское приложение для ведения направлений обучения и
roadmap. Оно хранит структуру тем, прогресс и следующие действия; обучение и
запуск пользовательского кода остаются во внешних инструментах.

> Скриншот будет добавлен после стабилизации интерфейса этапа 3.

Интерактивная карта проекта: [web/public/architecture.html](web/public/architecture.html).

## Требования

- Linux и современный браузер;
- Go 1.22+ с CGO и C-компилятором;
- Node.js 20+ и npm — только для разработки и production-сборки frontend.

## Быстрый запуск

Разработка (backend на `127.0.0.1:8080`, Vite на `127.0.0.1:5173`):

```sh
make dev
```

Для разработки откройте <http://127.0.0.1:5173>.

Production-сборка и запуск одним бинарником:

```sh
make build
./dist/learning-roadmap
```

Production-бинарник откройте на <http://127.0.0.1:8080>. При первом запуске приложение автоматически
создаст базу, применит миграции и импортирует roadmap `Backend Go`. Повторный
запуск seed не дублирует данные.

На экране Roadmap работают горячие клавиши: `Esc` закрывает активную форму/окно,
`N` открывает новую тему, `R` обновляет дерево. Поля ввода не перехватывают `N` и
`R`; страницу можно прокручивать обычным колесом мыши.

Клик по любой теме открывает быструю анимированную карточку: описание того, что изучить,
готовность, уверенность, следующий практический шаг и управление прогрессом.
Кнопка разворота в шапке карточки открывает её на весь экран; `Esc` возвращает к roadmap.

Главный экран «Сегодня» автоматически собирает из активных направлений темы для повторения,
просроченные сроки, доступные действия, блокировки зависимостями и активность за текущую неделю.

В разделе «Курсы» можно вручную создать курс, добавить модули и материалы (книги, видео,
репозитории, статьи, ссылки и локальные файлы), а также связать модуль с темой roadmap.
Импорт Markdown/JSON проходит обязательный preview: приложение сначала валидирует содержимое,
показывает состав курса и только затем записывает его в SQLite.

Если порт 8080 занят, укажите другой без открытия внешнего интерфейса:

```sh
./dist/learning-roadmap -port 18080
```

## Данные и конфигурация

По умолчанию используются:

- база: `~/.local/share/learning-roadmap/learning-roadmap.db`;
- конфигурация: `~/.config/learning-roadmap/config.json`;
- будущие резервные копии: `~/.local/share/learning-roadmap/backups/`;
- часовой пояс: `Europe/Moscow`.

Для изолированного запуска можно задать стандартные `XDG_CONFIG_HOME` и
`XDG_DATA_HOME`. Сервер всегда слушает только `127.0.0.1`.

## Архитектура

Приложение — модульный монолит: `net/http` JSON API и React UI работают с одной
SQLite-базой. SQL применяется через `database/sql`, схема меняется только
миграциями, а production frontend встраивается в Go-бинарник через `go:embed`.

```text
cmd/app/            точка входа
internal/config/    локальная конфигурация
internal/database/  открытие SQLite и миграции
internal/app/       Directions, Roadmap, Courses и HTTP API
migrations/         SQL-миграции
seeds/              идемпотентный Backend Go seed
web/                React, TypeScript и Vite
web/public/         статические материалы, включая карту архитектуры
dist/               production-бинарник
```

API использует префикс `/api/v1`; ошибки имеют единый вид
`{"error":{"code":"...","message":"...","details":{}}}`.

## Команды

```text
make dev             backend и frontend для разработки
make dev-backend     только Go backend
make dev-frontend    только Vite frontend
make build           frontend + production-бинарник
make test            все тесты
make test-backend    Go-тесты
make test-frontend   frontend-тесты
make lint            формат, go vet и TypeScript
make migrate         применить миграции и завершиться
make seed            применить seed и завершиться
make clean           удалить результаты сборки
```

## Импорт и резервные копии

Инструкция и шаблон roadmap: [docs/ROADMAP_IMPORT.md](docs/ROADMAP_IMPORT.md) и
[docs/roadmap-template.json](docs/roadmap-template.json). Произвольная JSON-загрузка
roadmap через UI пока остаётся отдельным будущим этапом.

Курсы импортируются прямо из раздела «Курсы» в формате Markdown или JSON. Сначала нажмите
«Показать preview», проверьте модули и материалы, затем — «Импортировать». Контракт и решения
описаны в [docs/COURSES_AND_MATERIALS_IMPLEMENTATION.md](docs/COURSES_AND_MATERIALS_IMPLEMENTATION.md).

Backup/restore пока не подключены. Планируемый backup будет содержать SQLite-файл,
JSON-экспорт и версию схемы; локальные учебные файлы копироваться не будут.

## Известные ограничения

- реализованы этапы 1–3 ТЗ: направления, roadmap, курсы и материалы;
- журнал, проекты, аналитика и backup пока отсутствуют;
- приложение рассчитано на одного локального пользователя и Linux;
- авторизация, синхронизация, мобильное приложение и запуск кода не входят в MVP.
